Several useful things here.

Panel B and C together are the most important. The non-zero CPUE on log scale (B) looks remarkably flat/uniform rather than bell-shaped — that’s not what I’d expect from a lognormal and the QQ-plot (C) confirms this: the middle of the distribution tracks the line reasonably well, but both tails deviate. The top four sites are almost certainly our outside or less-vegetated sites — worth checking.

Panel A just confirms the extreme right skew and those two outlier samples around 1250 and 2000 that are visible above the main mass.

What I’d do next: First, ask the group: what’s different about the groups in panel D, those with substantial frequencies of zero and those with none? Then, check whether the high-zero sites map onto a particular Type (inside/outside) or characteristic, and consider fitting a model with hu ~ Project_na or at minimum hu ~ Type to let zero probability vary. hurdle models

We fit a series of hurdle lognormal models of increasing complexity. All models include a random intercept for Year to account for inter-annual variation (as in the bivalve analysis). The hurdle component (probability of zero catch) is modelled separately; we start with a fixed hurdle intercept and can relax that later.

Models fitted:

model fixed effects (mu) fixed effects (hu)
m0 intercept only intercept only
m1 Type (in/out) intercept only
m2 Project_na intercept only

m4 Type + (1|Project_na) Type

Model m4 is the most flexible baseline: it includes a site-level random intercept, allows the non-zero mean to vary by inside/outside, and lets the hurdle probability differ by type.

# brms treats the intercept as class = Intercept (separate from class = b),
# so we split priors into a base set valid for all models and additive sets
# for models with fixed effects or a modelled hu component.

# valid for every model
priors_base <- c(
  prior(normal(5, 3), class = Intercept), # mu intercept (log scale)
  prior(normal(0, 1), class = Intercept, dpar = hu), # hu intercept (logit scale)
  prior(exponential(1), class = sd), # random effect SDs
  prior(exponential(1), class = sigma) # lognormal residual SD
)

# add to models that have mu fixed effects (m1–m4)
prior_b <- prior(normal(0, 1), class = b)

# add to models that have hu fixed effects (m4 only)
prior_b_hu <- prior(normal(0, 1), class = b, dpar = hu)

The model converged cleanly (all Rhat = 1.00, ESS well above 400 for all parameters). Here’s what each piece tells you:

Hurdle component (hu_Intercept = -1.73) plogis(-1.73) ≈ 0.15 — about 15% of FRP+SAV insect samples catch nothing. That’s a moderate zero rate, consistent with a hurdle model being appropriate but not dominated by zeros.

Lognormal component (Intercept = 3.51) The expected log-CPUE for a non-zero catch is 3.51, so the median CPUE on the raw scale is exp(3.51) ≈ 33 insects/volume. The wide CI (2.44–4.69) reflects genuine year-to-year variability being absorbed by the random effect.

Year random effect (sd = 1.03) This is large — on the log scale, a SD of 1 means years routinely differ by a factor of exp(1) ≈ 2.7 in median CPUE. With only 4 levels the estimate is uncertain (0.35–2.41), but it’s clearly non-trivial. This justifies keeping (1 | Year) in all subsequent models.

sigma = 1.66 Within-year, within-site residual variation on the log scale is also large. exp(1.66) ≈ 5.3, meaning even after accounting for year, individual tow catches vary by roughly 5-fold. Insects are patchy — that’s expected.

Bottom line for m0: ~15% zeros, median catch ~33/volume, but enormous variability both across years and within years. The year random effect is doing real work, and the wide sigma suggests site or type effects (m1–m4) might explain some of that residual spread. That’s exactly what you’ll find out from the comparisons.
